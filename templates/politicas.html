Politicas y condiciones

Ultima actualizacion: octubre 2026

1. Naturaleza del servicio

Esta es una aplicacion privada de mensajeria entre un numero limitado de usuarios autorizados. No es un servicio publico. Su finalidad es la comunicacion personal entre sus miembros.

2. Acceso

  • El acceso puede realizarse mediante token de un solo uso, huella digital o credenciales personales.
  • Cada usuario es responsable de mantener la confidencialidad de sus tokens, huellas y credenciales.
  • El token puede ser revocado en cualquier momento desde el panel de ajustes.

3. Tratamiento de mensajes

  • Los mensajes se almacenan mientras la conversacion siga activa.
  • En cualquier momento cualquier usuario puede borrar la totalidad de los mensajes mediante el boton de borrado total.
  • Tras el borrado total, los mensajes se eliminan de la base de datos y no son recuperables.
  • No se mantiene historial permanente una vez borrado.

4. Datos tecnicos

Se almacenan unicamente los datos minimos para el funcionamiento: identificador de usuario, hash de contraseña, PIN, huellas publicas registradas, tokens de acceso, suscripciones de notificacion y los mensajes intercambiados.

No se utilizan cookies de rastreo, analitica ni publicidad. No se comparten datos con terceros.

5. Notificaciones

Las notificaciones push se envian sin mostrar el contenido del mensaje ni la identidad del remitente, por motivos de privacidad. Solo indican que existe un mensaje nuevo.

6. Responsabilidad

Este servicio se ofrece tal cual, sin garantias de disponibilidad continua. El usuario acepta que el servicio puede interrumpirse por mantenimiento, actualizaciones o causas tecnicas ajenas.

7. Cambios

Estas condiciones pueden actualizarse. El uso continuado del servicio tras una actualizacion implica la aceptacion de los cambios.

8. Contacto

Para cualquier consulta relacionada con estas condiciones, contacta directamente con el administrador del servicio.

Al usar este servicio aceptas estas condiciones.
